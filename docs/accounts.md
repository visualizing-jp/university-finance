# 科目の対応

画面に出す金額は、各学校法人の計算書類（単位: 円）から取る。事業報告書の総括表は使わない。多摩美術大学と武蔵野美術大学は同じ科目の畳み方にする。武蔵野美術大学の出典は [財務状況](https://www.musabi.ac.jp/outline/disclose/financial/)。決算書が左右2段組の年は、同じ行の左右を別の科目として読む。親科目の行に金額が無いときは、国庫補助金と地方公共団体補助金を足して経常費等補助金にする。

初版は2015年度から最新年度まで。2015年度に消費収支計算書が事業活動収支計算書へ変わり、活動区分資金収支計算書が加わった。2014年度以前は、この系列には繋がない。

## 収支

事業活動収入を6つ、事業活動支出を4つに畳む。合計は事業活動収入計・事業活動支出計と一致させる。差額は基本金組入前当年度収支差額。

収入:

- 学生生徒等納付金
- 補助金 = 経常費等補助金 + 施設設備補助金
- 寄付金 = 教育活動の寄付金 + 施設設備寄付金 + 特別収入の現物寄付
- 付随事業収入
- 受取利息・配当金
- その他 = 手数料 + 雑収入 + その他の教育活動外収入 + 資産売却差額 + （その他の特別収入 − 施設設備寄付金 − 現物寄付 − 施設設備補助金）

支出:

- 人件費
- 教育研究経費
- 管理経費
- その他 = 徴収不能額等 + 借入金等利息 + その他の教育活動外支出 + 資産処分差額 + その他の特別支出

教育活動の現物寄付は寄付金の内数なので、重ねて足さない。

経常収入 = 教育活動収入計 + 教育活動外収入計。経常支出 = 教育活動支出計 + 教育活動外支出計。経常収支差額は、この差と計算書類の経常収支差額が一致する。

大学を比べるときの比率は、次の分母を使う。

- 事業活動収支差額比率 = 基本金組入前当年度収支差額 ÷ 事業活動収入
- 経常収支差額比率 = 経常収支差額 ÷ 経常収入
- 人件費比率、教育研究経費比率、管理経費比率、学生生徒等納付金比率 = それぞれの科目 ÷ 経常収入
- 補助金比率 = 経常費等補助金 ÷ 経常収入。施設設備補助金は特別収入なので、分子にも分母にも入れない
- 寄付金比率 = 教育活動の寄付金 ÷ 経常収入。施設設備寄付金と、特別収入の現物寄付は入れない
- 運用資産余裕比率 = （運用資産 − 外部負債）÷ 経常支出。単位は年
- 総負債比率 = 総負債 ÷ 総資産
- 流動比率 = 流動資産 ÷ 流動負債

外部負債 = 長期借入金 + 短期借入金 + 1年以内に返済する長期借入金 + 学校債 + 未払金 + 支払手形。無い科目は0。長期未払金と総負債そのものは含めない。

## 資産・負債

貸借対照表の本年度末。

- 左: 固定資産、流動資産
- 右: 固定負債、流動負債、基本金、繰越収支差額

繰越収支差額が負の年は、基本金から差し引いて純資産にする。左右の合計は資産合計で一致する。

運用資産 = 現金預金 + 特定資産 + 有価証券（その他の固定資産および流動資産にある有価証券。特定資産の内数は特定資産に含まれる）。

## 資金の流れ

活動区分資金収支計算書の差額。

前年度繰越支払資金 + 教育活動資金収支差額 + 施設整備等活動資金収支差額 + その他の活動資金収支差額 = 翌年度繰越支払資金

翌年度繰越支払資金は、貸借対照表の現金預金と一致する。当年の翌年度繰越は、翌年の前年度繰越と一致する。

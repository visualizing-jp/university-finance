# 科目の対応

画面に出す金額は、学校法人多摩美術大学の計算書類（単位: 円）から取る。事業報告書の総括表は使わない。

初版は2015年度から最新年度まで。2015年度に消費収支計算書が事業活動収支計算書へ変わり、活動区分資金収支計算書が加わった。2014年度以前は、この系列には繋がない。

## 収支

事業活動収入を6つ、事業活動支出を4つに畳む。合計は事業活動収入計・事業活動支出計と一致させる。差額は基本金組入前当年度収支差額。

収入:

- 学生生徒等納付金
- 補助金 = 経常費等補助金 + 施設設備補助金
- 寄付金 = 教育活動の寄付金 + 施設設備寄付金 + 特別収入の現物寄付
- 付随事業収入
- 受取利息・配当金
- その他 = 手数料 + 雑収入 + その他の教育活動外収入 + 資産売却差額 + （その他の特別収入 − 施設設備寄付金 − 現物寄付 − 施設設備補助金）

支出:

- 人件費
- 教育研究経費
- 管理経費
- その他 = 徴収不能額等 + 借入金等利息 + その他の教育活動外支出 + 資産処分差額 + その他の特別支出

教育活動の現物寄付は寄付金の内数なので、重ねて足さない。

## 資産・負債

貸借対照表の本年度末。

- 左: 固定資産、流動資産
- 右: 固定負債、流動負債、基本金、繰越収支差額

繰越収支差額が負の年は、基本金から差し引いて純資産にする。左右の合計は資産合計で一致する。

運用資産 = 現金預金 + 特定資産 + 有価証券（その他の固定資産および流動資産にある有価証券。特定資産の内数は特定資産に含まれる）。

## 資金の流れ

活動区分資金収支計算書の差額。

前年度繰越支払資金 + 教育活動資金収支差額 + 施設整備等活動資金収支差額 + その他の活動資金収支差額 = 翌年度繰越支払資金

翌年度繰越支払資金は、貸借対照表の現金預金と一致する。当年の翌年度繰越は、翌年の前年度繰越と一致する。
